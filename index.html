暗号の解説 ＆ 豆知識

CTFでよく狙われる主要な形式の特徴と、解析に役立つ豆知識です。

📝 Base64（ベースロクヨン）

頻出度: ★★★

【特徴】 データを「A〜Z」「a〜z」「0〜9」と「+」「/」の**計64種類の文字**だけで表現する形式です。厳密には暗号ではなく、データを扱いやすくするための「エンコード（符号化）」です。

【豆知識・見分け方】

  • 末尾に = や == というパディング（穴埋め文字）がついていることが多い。
  • アルファベットの大文字・小文字・数字がランダムに混ざっている。
  • CTFでは、画像データ（PNGなど）をBase64に変換して問題に埋め込む手法が非常によく使われます。

🔢 Hex（16進数表記）

頻出度: ★★★

【特徴】 コンピュータの生データを人間の目に見えるように、**「0〜9」と「a〜f（またはA〜F）」の16種類の文字**で表現したものです。2文字で「1バイト」のデータを表します。

【豆知識・見分け方】

  • 文字の中に g 以降のアルファベット（g, h, i...など）が**絶対に出てこない**のが最大の特徴。
  • 先頭に 0x がついていたり、2文字ごとにスペースで区切られていることが多い。
  • CTFでは、ファイルの先頭データ（マジックナンバー）をHexで読み解き、隠されたファイル形式（PNGなら 89 50 4E 47）を突き止める際に必須の知識になります。

💻 Binary（2進数表記）

頻出度: ★★☆

【特徴】 コンピュータの最小単位である**「0」と「1」だけ**で表現されたデータです。ASCIIコードでは、通常8桁（1バイト）のペアで1つのアルファベットや記号を表します。

【豆知識・見分け方】

  • 01000001 のように、「0」と「1」しか出現しないのが最大の特徴。
  • 8桁（または8の倍数の桁数）ごとにスペースで区切られていることが多い。
  • CTFでは、通信の生データ解析やシリアル通信のキャプチャデータなどで頻出します。

🏛️ Caesar 暗号（シーザー暗号）

頻出度: ★★☆

【特徴】 アルファベットを指定した文字数分だけ「ずらす」古典的な暗号方式です。

【豆知識・見分け方】

  • 文字数（26文字）が決まっているため、最大25パターンを試す「ブルートフォース（総当たり）」で簡単に解読可能です。
  • 13文字ずらす設定は特に ROT13 と呼ばれ、ネット上のネタバレ防止にも広く使われています。

🔄 Atbash 暗号（アトバシュ暗号）

頻出度: ★☆☆

【特徴】 アルファベットの順序を完全に対称に反転させる暗号です（A ↔ Z、B ↔ Y ...）。

【豆知識・見分け方】

  • 暗号化と復号化（元の文に戻す処理）が全く同じアルゴリズムで行える特徴を持っています。

🗝️ Vigenere 暗号（ヴィジュネル暗号）

頻出度: ★★☆

【特徴】 「鍵（Key）」となるキーワードの各文字を使って、アルファベットのずらし量を文字ごとに変化させる古典的な多表式暗号です。

【豆知識・見分け方】

  • 暗号文と同時に「KEY」や「SECRET」といった文字列（鍵）が与えられるのが特徴。
  • シーザー暗号と異なり、同じ文字でも位置によって異なる文字に暗号化されるため解読が少し複雑になります。
  • 記号（_ や { など）はシフト処理を行わず、鍵の進みもスキップするのが標準的なルールです。

🌐 URLエンコード（パーセントエンコーディング）

頻出度: ★★★

【特徴】 Webブラウザのアドレスバーなどで、スペースや特殊文字を安全に送信するために**「% + 16進数2桁」**に変換する方式です。

【豆知識・見分け方】

  • 文字列の中に %20 や %48%65%6c のように % が連続して出現するのが目印。
  • Webセキュリティの分野（SQLインジェクションやXSSなどの攻撃ペイロード分析）で頻繁に遭遇します。

🏷️ HTMLエンティティ（実体参照）

頻出度: ★★☆

【特徴】 Webページ上でタグとして誤認される可能性のある記号（< や > など）を、安全に画面表示するために特殊な文字列へとエスケープする形式です。

【豆知識・見分け方】

  • 先頭が &（アンパサンド）で始まり、末尾が ;（セミコロン）で終わるのが基本形（例: &lt; = <）。
  • Webサイトのソースコードを読み解くCTF問題（Webジャンル）でよく出題されます。

🔒 暗号学的ハッシュ値（Hash）

頻出度: ★★★

【特徴】 入力データから固定長の不可逆な値を生成するアルゴリズムです。元データへの復元は基本的に不可能で、文字の長さ（桁数）でアルゴリズムを推測します。

【豆知識・見分け方】

  • MD5: 32桁の16進数（128ビット）
  • SHA-1: 40桁の16進数（160ビット）
  • SHA-256: 64桁の16進数（256ビット）
  • 16進数（0〜9, a〜f）のみで構成されており、桁数を見るだけで一発で識別できます。
